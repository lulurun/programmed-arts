# Programmed Arts

Parametric browser-based tools for creating printable programmed art.

## Projects

- [fish-pattern](fish-pattern/) - an ellipse-based fish motif editor and A0 layout tool.

## Run

Run the fish-pattern tool:

```bash
npm start
```

Then open:

```text
http://localhost:4173/fish-pattern/
```

## Checks

```bash
npm run check
```
